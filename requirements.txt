# CPU-only PyTorch wheels. Install everything with a single `pip install -r
# requirements.txt` invocation (not package-by-package), and avoid mixing
# `--user` and system-wide installs for numpy/torch/transformers. On Windows,
# if torch ends up in a *different* site-packages root than numpy (e.g. one
# user-installed, one system-installed), its native DLLs (c10.dll and
# friends) can fail to load at import time ("OSError: [WinError 1114] A
# dynamic link library (DLL) initialization routine failed") even though the
# install itself reports success - the fix is reinstalling torch into the
# same site-packages root as numpy/transformers (edgecases.md S4-01).
# Harmless on Linux/macOS too.
--extra-index-url https://download.pytorch.org/whl/cpu
